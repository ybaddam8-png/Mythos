# CORE ARCHITECTURE

The most important part I'd have the coding agent implement is this:

```text
                    ┌───────────────────┐
                    │   Web Frontend    │
                    │ React / Next.js   │
                    └─────────┬─────────┘
                              │
                              ▼
                    ┌───────────────────┐
                    │   Story API       │
                    │     FastAPI       │
                    └─────────┬─────────┘
                              │
                ┌─────────────┼──────────────┐
                ▼             ▼              ▼
       ┌──────────────┐ ┌────────────┐ ┌──────────────┐
       │ Story Engine │ │ Prompt     │ │ Database     │
       │              │ │ Builder    │ │              │
       └──────┬───────┘ └─────┬──────┘ └──────────────┘
              │               │
              │               ▼
              │      ┌──────────────────┐
              │      │ Pretrained       │
              │      │ GPT-2 / GPT-Neo  │
              │      └────────┬─────────┘
              │               │
              └───────────────┘
                      │
                      ▼
             ┌───────────────────┐
             │ Updated World     │
             │ State             │
             │                   │
             │ Characters        │
             │ Inventory         │
             │ Quests            │
             │ Decisions         │
             │ Timeline          │
             └───────────────────┘
```

### The key difference from a basic AI storyteller

Don't make:

**Prompt → GPT → Text**

Make:

**Prompt → AI → Narrative → State extraction → World state update → New context → Next narrative**

That turns it from a simple **"AI text generator"** into an actual **interactive storytelling system**.

And it stays aligned with the internship's original requirement of using a pretrained GPT-2/GPT-Neo model, prompt-based generation, multiple continuations, genre selection and story saving rather than requiring you to train a model yourself. :chatgpt-content-reference{index="2"}
